# wazabin-sleigh-precompile

SLEIGH processor specifications compiled at build time and embedded in the
binary.

Compiling a real specification takes hundreds of milliseconds — too long to do
at program start, and far too long to do in a test. This crate compiles a fixed
set once, during its own build, serialises them, and embeds the result. Loading
is a deserialisation on first use, cached behind a `OnceLock`.

```rust
use sleigh::Decoder;

let spec = sleigh_precompile::x64::spec();
let decoder = Decoder::new(spec);
```

Which specifications are built is configured in `build_config.toml`; their
sources come from the vendored Ghidra corpus under `open_sleigh/`. Each module
also exposes named `RegisterId` constants generated alongside its
specification.

The embedded form is `bincode` over this crate's `sleigh` dependency and is
only valid for that exact version, which is why it is regenerated by the build
script rather than checked in.
